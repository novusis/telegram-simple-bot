
# Trikonasana Yoga — статичный сайт (HTML + CSS)

Готовая верстка без JS и бэкенда. Современный дизайн, легко масштабировать.

## Структура
- `index.html` — главная (герой, преимущества, поп. курсы, CTA)
- `courses.html` — все курсы (карточки)
- `course-*.html` — страницы курсов (обложка, описание, список уроков, сайдбар)
- `about.html` — об авторе
- `testimonials.html` — отзывы
- `assets/css/style.css` — стили (переменные, компоненты, сетки)
- `assets/img/*` — логотип, плейсхолдеры, фавикон, аватары

## Как развернуть
1. Скопируйте папку `yoga-site` на любой хостинг статических файлов.
2. Домашняя страница — `index.html`.
3. Для добавления нового курса:
   - Скопируйте один из `course-*.html`, переименуйте (например, `course-yin.html`).
   - Замените заголовок, картинку, описание и список уроков (см. блок `<section> Программа курса`).
   - Добавьте карточку курса на `courses.html` и, при желании, на блок «Популярные курсы» в `index.html`.
4. Замените плейсхолдер‑изображения файлами ваших обложек в `assets/img/`, обновите пути.
5. В подвале (`footer`) обновите контакты и ссылки на соцсети.

## Кастомизация
- Цвета и закругления задаются CSS‑переменными в `:root`.
- Компонентный подход: .card, .btn, .badge, .lesson, .grid, .section, .container — можно переиспользовать.
- Хедер — адаптивное меню без JS (checkbox‑hack).

## SEO
- Отредактируйте `<title>` и `<meta name="description">` под каждую страницу.

Удачного запуска!
